# แบบทดสอบการใช้งาน Qlass (UAT / แบบทดสอบพนักงาน)

เวอร์ชัน 1.1 · ปรับปรุง 8 ก.ย. 2569

> ชุดเดียวกับแท็บ “แบบทดสอบ” ในเมนู “📖 คู่มือการใช้งาน” ของแอป (ในแอปติ๊กผ่าน/ไม่ผ่านและคัดลอกสรุปผลได้) ไฟล์นี้เป็นฉบับพิมพ์

## วิธีใช้เอกสารนี้ (อ่านก่อนเริ่ม)

1. แต่ละข้อให้ “คนเดียว” ทำ โดยเข้าสู่ระบบด้วยบทบาทใดบทบาทหนึ่งที่ระบุไว้ (ไม่ต้องให้ทุกบทบาททำซ้ำ) ทีมที่แนะนำ: หัวหน้าแอดมิน 1 + ผู้จัดการสาขา 1 + แคชเชีย 2 — ประมาณ 20 ข้อต้องใช้บทบาทหัวหน้าแอดมิน/แอดมินขึ้นไป (เมนูค่าคอม คิวว่าง ประวัติการลบ จัดการพนักงาน/โปร/หัตถการ) ถ้าไม่มีให้ข้ามและจดไว้ ในแอปแท็บนี้จะกรองข้อตามบทบาทที่เลือกให้เอง
2. ทำเรียงตามหมายเลข และข้อที่อยู่ “สายเดียวกัน” (ดูด้านล่าง) ต้องให้คนเดียวกันทำต่อกัน เพราะใช้ข้อมูลทดสอบร่วมกัน — ช่องเวลาที่เอกสารระบุ (15:00 / 16:00 / 18:00) ถ้ามีคิวจริงจองอยู่ ให้ใช้ช่องว่างใกล้ที่สุดแล้วจดไว้
3. คำว่า วันนี้ / พรุ่งนี้ / มะรืน นับจาก “วันที่ทดสอบ” ไม่ใช่วันที่ในเอกสาร
4. ใช้ข้อมูลทดสอบตามชื่อที่ระบุในแต่ละข้อ (ขึ้นต้น “ทดสอบ-”) และเลือกทดสอบใน 1 สาขาที่ตกลงกันไว้ — ข้อมูลทดสอบจะไหลเข้ารายงาน/ตัวเลขข้างเมนูของวันนั้นทันที ให้ถือว่าตัวเลขของวันทดสอบไม่ใช้งานจริง และลบข้อมูลทดสอบให้เสร็จในวันเดียวกันตามรายการท้ายเอกสาร
5. ทำตาม “ขั้นตอน” แล้วเทียบกับ “ผลที่ต้องได้” ทุกข้อ ตรงทั้งหมด = ✅ ผ่าน ถ้ามีข้อใดไม่ตรง = ❌ ไม่ผ่าน และพิมพ์สิ่งที่เห็นจริงในช่องหมายเหตุ (พร้อมภาพหน้าจอ) ถ้าขึ้น “ตรวจสอบเวลาห้องไม่สำเร็จ…” หรือ “บันทึกไม่สำเร็จ…” ให้ลองใหม่ก่อน เป็นเรื่องอินเทอร์เน็ต ไม่ใช่ไม่ผ่าน
6. ข้อที่ต้องทำ “หลัง 12:00” (P-46) ให้จัดไว้ช่วงบ่าย และต้องมีคิว “ลงล่วงหน้า” ไว้ตั้งแต่วันก่อนทดสอบ (ดู P-00)
7. แบบทดสอบความเข้าใจ (ปรนัย): ทำหลังอ่านคู่มือ ทุกคนทำในแอปด้วยบทบาทตัวเอง ระบบจะแสดงเฉพาะข้อของบทบาทนั้นและคิดคะแนนให้ เกณฑ์ผ่าน 80% (ในเอกสาร: ข้อที่มีวงเล็บบทบาท ให้ตอบเฉพาะเมื่อเป็นบทบาทของคุณ และนับฐานคะแนนจากข้อที่ต้องตอบ)
8. เวลาโดยประมาณ: ภาคปฏิบัติ 5 นาที/ข้อ (ข้อที่ใช้ 2 เครื่อง, Export, Backup และ P-02b ใช้นานกว่า) ทีม 4 คนแบ่งกัน ≈ 2–2.5 ชั่วโมง + เก็บกวาด 30 นาที + ปรนัยทำท้ายสุดคนละ 20 นาที — งานทั้งหมดของวันทดสอบใช้ครึ่งวันบ่าย

- **สายที่ 4 — ตั้งค่าห้อง (หัวหน้าแอดมิน/ผู้จัดการสาขา):** P-85 → P-86 → P-87 → P-88 → P-90
- **สายที่ 5 — ตารางห้อง/เครื่อง:** P-91 → P-92 → P-93 → P-94
- **สายที่ 6 — พนักงานทดสอบ (หัวหน้าแอดมิน) — ลบบัญชีทดสอบเป็นข้อสุดท้ายของวัน:** P-95 → P-96 → P-97 → P-65 → P-02b → P-98
- **คู่ 2 เครื่อง — แคชเชีย 2 คนทำพร้อมกัน:** P-15 → P-48
