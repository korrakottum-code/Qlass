# ads-spend — สำเนาที่ดึงกลับมาจากของจริง (16 ก.ย. 2569)

ฟังก์ชันนี้ **รันอยู่ในโปรดักชันมาตั้งแต่ประมาณ 18 ส.ค. 2569** (เวอร์ชัน 7, แก้ล่าสุด 20 ส.ค.)
แต่โค้ดไม่เคยถูก merge เข้า `main` เลย — มันมาจาก PR #159 ซึ่งถูกปิดไปเมื่อ 16 ก.ย. 2569

ไฟล์ `index.ts` ในโฟลเดอร์นี้คือสำเนาที่ดึงกลับมาจากฟังก์ชันที่รันอยู่จริง **ห้ามแก้**
ถ้าไม่ได้ตั้งใจจะ deploy ทับ เพราะคุณค่าเดียวของมันตอนนี้คือ "ตรงกับของจริงทุกตัวอักษร"

## สถานะตอนนี้

| หัวข้อ | ค่า |
|---|---|
| deploy อยู่จริง | ใช่ (slug `ads-spend`) |
| `verify_jwt` | `false` (ฟังก์ชันตรวจ session ของ Qlass เอง ผ่าน header `x-qlass-session`) |
| entrypoint ตอน deploy | `index.ts` (ไม่ได้อยู่ใต้ `supabase/functions/`) |
| มีใครเรียกใช้ไหม | **ไม่มี** — `src/components/AdSpendCard.jsx` ใน `main` ยังดึงจาก Google Sheet สาธารณะเหมือนเดิม |
| secret ที่ต้องมี | `QLASS_ADS_SPEND_URL`, `QLASS_ADS_SPEND_TOKEN` |
| สิทธิ์ | เฉพาะ role `superadmin` |

## ทำไมต้องเก็บไว้

ฟังก์ชันที่รันอยู่แต่ไม่มีโค้ดใน repo คือของที่ไม่มีใครตรวจได้ ไม่มีใครรู้ว่าแก้อะไรไป
และวันที่มันพังจะไม่มีต้นฉบับให้ย้อนดู เก็บสำเนาไว้ก่อน แล้วค่อยตัดสินใจทีหลังว่าจะ
เอาฝั่งหน้าจอมาต่อให้ครบ หรือจะลบฟังก์ชันนี้ทิ้งไปเลย
